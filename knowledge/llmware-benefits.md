# Why LLMWare

LLMWare offers a unified ModelCatalog for local and hosted models, document parsing, knowledge libraries, embeddings, retrieval, prompts with sources and small specialized models for RAG, classification, extraction and summarization.

Local execution keeps prompts and private enterprise context inside the controlled environment. Small quantized models can run on developer laptops or CPU nodes, while larger models can be moved to a dedicated inference server without changing the surrounding API contract.
